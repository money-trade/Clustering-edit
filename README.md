# Knn-classroom

แบ่งกลุ่มหน้าเพื่อนในห้องจากรูปใน `dataset/` ด้วย **K-means ที่เขียนคำนวณมือทั้งหมด** (Python ล้วน ไม่ใช้ไลบรารีคำนวณ)

> ชื่อ repo มาจากเวอร์ชันแรกที่ใช้ KNN จดจำหน้าผ่านกล้อง ตอนนี้เหลือเฉพาะการแบ่งกลุ่มจาก dataset
> ไม่มีการเปิดกล้อง และไม่มีการบันทึกไฟล์ใด ๆ

## ไฟล์ในโปรเจค

| ไฟล์ | หน้าที่ |
|---|---|
| `face_utils.py` | อ่านรูปใน `dataset/` หาหน้าแล้วตัดเฉพาะหน้า |
| `cluster.py` | หาหน้าเฉลี่ยต่อคน ปรับแสง แบ่งกลุ่มด้วย K-means (คำนวณมือ) แล้วแสดงภาพผล |
| `dataset/` | รูปนักเรียน 32 คน คนละ 1 รูป |

## ติดตั้ง

ทดสอบกับ Python 3.14

```bash
pip install opencv-python numpy
```

- **OpenCV** ใช้อ่านรูป หาหน้า (Haar Cascade) และวาด/แสดงภาพเท่านั้น
- **NumPy** ใช้ใน `face_utils.py` ตอนตัดหน้า และใน `cluster.py` ตอนสร้างภาพให้ `cv2.imshow` เท่านั้น
- การคำนวณจัดกลุ่มทั้งหมดไม่ใช้ทั้งสองตัว

## วิธีใช้

1. ใส่รูปไว้ใน `dataset/` ตั้งชื่อไฟล์เป็น `รหัส_ชื่อ.jpg` เช่น `6752300046_Taer.jpg`
   - 1 คนมีหลายรูปได้ เช่น `6752300046_Taer_2.jpg` (ระบบใช้หน้าเฉลี่ยของคนนั้น)
   - รองรับ .jpg .png .bmp .webp ส่วน .heif (รูปจาก iPhone) ต้องแปลงเป็น .jpg ก่อน
   - รูปที่อ่านไม่ได้หรือหาหน้าไม่เจอ จะถูกข้ามและแจ้งชื่อไฟล์ในหน้าจอ
2. เปิด terminal **ในโฟลเดอร์ `Clustering-edit`** แล้วรัน (ถ้าไม่เจอคำสั่ง `python` ให้ใช้ `py cluster.py`)

```bash
python cluster.py
```

3. รอสักครู่ (คำนวณมือจึงช้ากว่าใช้ไลบรารี) แล้วจะเห็นผล 2 แบบ
   - **ใน terminal**: สมาชิกของแต่ละกลุ่ม เช่น `กลุ่ม 1 (11 คน): Jack, Arm, ...`
   - **หน้าต่างรูป**: 1 แถว = 1 กลุ่ม เรียงเป็น ชื่อกลุ่ม → สมาชิกพร้อมชื่อ
     คลิกที่หน้าต่างแล้วกดปุ่มใดก็ได้เพื่อปิด

## ตั้งค่า (ด้านบนของ `cluster.py`)

| ค่า | ปัจจุบัน | ความหมาย |
|---|---|---|
| `k` | `4` | จำนวนกลุ่ม |
| `SEED` | `42` | seed ของตัวสุ่ม ให้ผลเหมือนเดิมทุกครั้ง |
| `N_TRIES` | `10` | สุ่มจุดเริ่มต้นใหม่กี่ครั้ง แล้วเลือกครั้งที่ผลรวมระยะน้อยที่สุด |
| `MAX_ITER` | `100` | จำนวนรอบวนสูงสุดต่อ 1 ครั้ง |
| `EPS` | `0.01` | หยุดเมื่อศูนย์กลางกลุ่มขยับน้อยกว่าค่านี้ |

## หลักการทำงาน

### 1. ตัดหน้า (`face_utils.py`)

รูปใน dataset ถ่ายมาไม่เหมือนกัน บางรูปเต็มตัว บางรูปชิดหน้ามาก ถ้าเอาทั้งรูปมาเทียบ
ระบบจะแบ่งตาม "ระยะถ่าย" แทนที่จะเป็น "หน้า" จึงต้องตัดให้ทุกรูปเป็นแบบเดียวกันก่อน

1. ตัดกรอบสีเรียบที่ติดมากับบางรูปออก
2. หาหน้าด้วย Haar Cascade (มากับ OpenCV)
3. ตัดเฉพาะช่วงหน้าผากถึงคาง แก้มถึงแก้ม แล้วย่อเป็นภาพขาวดำ 140×180

### 2. แบ่งกลุ่ม (`cluster.py`) คำนวณมือทั้งหมด

| ขั้น | ฟังก์ชัน | ทำอะไร |
|---|---|---|
| หน้าเฉลี่ยต่อคน | `mean_vectors` | เฉลี่ยทีละพิกเซลของทุกรูปของคนเดียวกัน |
| ปรับแสง | `equalize_hist` | นับ histogram → ผลรวมสะสม (CDF) → แปลงค่าพิกเซลให้กระจายเท่ากัน |
| ระยะทาง | `sq_dist` | ระยะยูคลิดยกกำลังสองระหว่างสองภาพ (25,200 ค่า) |
| จุดเริ่มต้น | `kmeans_pp_init` | k-means++ สุ่มจุดให้อยู่ห่างกัน |
| จัดกลุ่ม | `kmeans_once` | วนซ้ำ: ให้แต่ละคนเข้ากลุ่มที่ใกล้สุด → คำนวณศูนย์กลางใหม่เป็นค่าเฉลี่ยสมาชิก → หยุดเมื่อนิ่ง (มีจัดการกลุ่มว่าง) |
| เลือกผลดีสุด | `kmeans` | ทำซ้ำ `N_TRIES` ครั้ง เลือกครั้งที่ผลรวมระยะกำลังสองน้อยที่สุด |

K-means แบ่งตามความเหมือนของภาพขาวดำทีละพิกเซลเท่านั้น ไม่ได้ใช้เกณฑ์ที่ตั้งไว้ล่วงหน้า
