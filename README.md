# Knn-classroom

แบ่งกลุ่มหน้าเพื่อนในห้องจากรูปใน `dataset/` ด้วย **K-means ที่เขียนคำนวณมือทั้งหมด** (Python ล้วน ไม่ใช้ไลบรารีคำนวณ)

> ชื่อ repo มาจากเวอร์ชันแรกที่ใช้ KNN จดจำหน้าผ่านกล้อง ตอนนี้เหลือเฉพาะการแบ่งกลุ่มจาก dataset
> ไม่มีการเปิดกล้อง และไม่บันทึกไฟล์ใด ๆ (ยกเว้นเปิด `SAVE_IMAGE = True` เพื่อบันทึกภาพผล)

## ไฟล์ในโปรเจค

| ไฟล์ | หน้าที่ |
|---|---|
| `face_utils.py` | อ่านรูปใน `dataset/` หาหน้าแล้วตัดเฉพาะหน้า |
| `cluster.py` | หาหน้าเฉลี่ยต่อคน ปรับแสง แบ่งกลุ่มด้วย K-means (คำนวณมือ) แล้วแสดงภาพผล |
| `dataset/` | รูปนักเรียน 32 คน คนละ 1 รูป |
| `requirements.txt` | ไลบรารีที่ต้องติดตั้ง (OpenCV เวอร์ชัน 4 + NumPy) |

## ติดตั้ง

ทดสอบกับ Python 3.14

```bash
pip install -r requirements.txt
```

> ต้องใช้ **OpenCV เวอร์ชัน 4** (`opencv-python<5`) เพราะ OpenCV 5.0 ถอด `cv2.CascadeClassifier` (Haar Cascade) ออกแล้ว
> ถ้าติดตั้ง 5.0 ไปแล้ว ให้รัน `pip install "opencv-python<5"`

- **OpenCV** ใช้อ่านรูป หาหน้า (Haar Cascade) และวาด/แสดงภาพเท่านั้น
- **NumPy** ใช้ใน `face_utils.py` ตอนตัดหน้า และใน `cluster.py` ตอนสร้างภาพให้ `cv2.imshow` เท่านั้น
- การคำนวณจัดกลุ่มทั้งหมดไม่ใช้ทั้งสองตัว

## วิธีใช้

1. ใส่รูปไว้ใน `dataset/` ตั้งชื่อไฟล์เป็น `รหัส_ชื่อ.jpg` เช่น `6752300046_Taer.jpg`
   - 1 คนมีหลายรูปได้ เช่น `6752300046_Taer_2.jpg` (ระบบใช้หน้าเฉลี่ยของคนนั้น)
   - รองรับ .jpg .png .bmp .webp ส่วน .heif (รูปจาก iPhone) ต้องแปลงเป็น .jpg ก่อน
   - รูปที่อ่านไม่ได้หรือหาหน้าไม่เจอ และไฟล์ที่ไม่ใช่รูป จะถูกข้ามและแจ้งชื่อไฟล์ในหน้าจอ
   - ถ้ารหัสหน้า `_` ไม่ใช่ตัวเลข 10 หลัก จะมีคำเตือนให้ตรวจชื่อไฟล์
   - ชื่อซ้ำกัน (เช่น First 2 คน) ระบบต่อท้ายด้วยเลข 4 ตัวท้ายของรหัสให้อัตโนมัติ เช่น `First(0607)`
2. เปิด terminal **ในโฟลเดอร์ `Clustering-edit`** แล้วรัน (ถ้าไม่เจอคำสั่ง `python` ให้ใช้ `py cluster.py`)

```bash
python cluster.py
```

3. รอสักครู่ (คำนวณมือจึงช้ากว่าใช้ไลบรารี) แล้วจะเห็นผล 2 แบบ
   - **ใน terminal**: สมาชิกของแต่ละกลุ่มพร้อม silhouette เฉลี่ยของกลุ่ม เช่น `กลุ่ม 1 (11 คน, silhouette 0.096): Jack, Arm, ...`
     ตามด้วย silhouette เฉลี่ยทั้งหมด และรายชื่อคนที่ silhouette ติดลบ (ใกล้กลุ่มอื่นมากกว่า)
   - **หน้าต่างรูป**: 1 แถว = 1 กลุ่ม เรียงเป็น หน้าเฉลี่ยของกลุ่ม (มีกรอบ) → สมาชิกพร้อมชื่อและค่า silhouette (`s=`)
     คลิกที่หน้าต่างแล้วกดปุ่มใดก็ได้เพื่อปิด

## ตั้งค่า (ด้านบนของ `cluster.py`)

| ค่า | ปัจจุบัน | ความหมาย |
|---|---|---|
| `k` | `4` | จำนวนกลุ่ม (ใช้เมื่อ `AUTO_K = False`) |
| `AUTO_K` | `False` | `True` = ลองทุก k ใน `K_RANGE` แล้วเลือกค่าที่ silhouette เฉลี่ยสูงสุด |
| `K_RANGE` | `range(2, 7)` | ช่วงของ k ที่ลองเมื่อ `AUTO_K = True` (ใช้เวลานานขึ้นประมาณ 5 เท่า) |
| `SEED` | `42` | seed ของตัวสุ่ม ให้ผลเหมือนเดิมทุกครั้ง |
| `N_TRIES` | `10` | สุ่มจุดเริ่มต้นใหม่กี่ครั้ง แล้วเลือกครั้งที่ผลรวมระยะน้อยที่สุด |
| `MAX_ITER` | `100` | จำนวนรอบวนสูงสุดต่อ 1 ครั้ง |
| `EPS` | `0.01` | หยุดเมื่อศูนย์กลางกลุ่มขยับน้อยกว่าค่านี้ |
| `SAVE_IMAGE` | `False` | `True` = บันทึกภาพผลเป็น `result_groups.png` ข้าง `cluster.py` |

## หลักการทำงาน

### 1. ตัดหน้า (`face_utils.py`)

รูปใน dataset ถ่ายมาไม่เหมือนกัน บางรูปเต็มตัว บางรูปชิดหน้ามาก ถ้าเอาทั้งรูปมาเทียบ
ระบบจะแบ่งตาม "ระยะถ่าย" แทนที่จะเป็น "หน้า" จึงต้องตัดให้ทุกรูปเป็นแบบเดียวกันก่อน

1. ตัดกรอบสีเรียบที่ติดมากับบางรูปออก
2. หาหน้าด้วย Haar Cascade (มากับ OpenCV)
3. ตัดเฉพาะช่วงหน้าผากถึงคาง แก้มถึงแก้ม แล้วย่อเป็นภาพขาวดำ 140×180

### 2. แบ่งกลุ่ม (`cluster.py`) คำนวณมือทั้งหมด

| ขั้น | ฟังก์ชัน | ทำอะไร |
|---|---|---|
| หน้าเฉลี่ยต่อคน | `mean_vectors` | เฉลี่ยทีละพิกเซลของทุกรูปของคนเดียวกัน |
| ปรับแสง | `equalize_hist` | นับ histogram → ผลรวมสะสม (CDF) → แปลงค่าพิกเซลให้กระจายเท่ากัน |
| ระยะทาง | `sq_dist` | ระยะยูคลิดยกกำลังสองระหว่างสองภาพ (25,200 ค่า) |
| จุดเริ่มต้น | `kmeans_pp_init` | k-means++ สุ่มจุดให้อยู่ห่างกัน |
| จัดกลุ่ม | `kmeans_once` | วนซ้ำ: ให้แต่ละคนเข้ากลุ่มที่ใกล้สุด → คำนวณศูนย์กลางใหม่เป็นค่าเฉลี่ยสมาชิก → หยุดเมื่อนิ่ง (มีจัดการกลุ่มว่าง) |
| เลือกผลดีสุด | `kmeans` | ทำซ้ำ `N_TRIES` ครั้ง เลือกครั้งที่ผลรวมระยะกำลังสองน้อยที่สุด |
| ตารางระยะ | `pairwise_dist` | ระยะยูคลิดระหว่างทุกคู่ คำนวณครั้งเดียว |
| วัดคุณภาพ | `silhouette` | ต่อคน: (b − a) / max(a, b) โดย a = ระยะเฉลี่ยถึงเพื่อนในกลุ่ม, b = ระยะเฉลี่ยถึงกลุ่มอื่นที่ใกล้สุด |

**อ่านค่า silhouette**: ใกล้ 1 = อยู่ถูกกลุ่มชัดเจน, ใกล้ 0 = อยู่กึ่งกลางระหว่างกลุ่ม, ติดลบ = ใกล้กลุ่มอื่นมากกว่ากลุ่มตัวเอง

K-means แบ่งตามความเหมือนของภาพขาวดำทีละพิกเซลเท่านั้น ไม่ได้ใช้เกณฑ์ที่ตั้งไว้ล่วงหน้า

### ผลล่าสุด (32 คน, k = 4, รันวันที่ 13 พ.ย. 2026)

| กลุ่ม | silhouette | สมาชิก |
|---|:-:|---|
| 1 (11 คน) | 0.096 | Jack, Arm, Max, Kong, Soda, tonkla, Ter, Ice, Praewa, Poom, Panda |
| 2 (8 คน) | 0.060 | Taer, Bank, Memi, nut, tine, First(0607), Film, Rem |
| 3 (6 คน) | 0.103 | Mek, Teerapat, Gumpun, T, Manow, camp |
| 4 (7 คน) | 0.195 | Kang, Mew, jimmy, Phai, Pang, First(1115), Earn |

- silhouette เฉลี่ยทั้งหมด **0.110** (แยกกลุ่มได้ไม่ชัด)
- Jack (−0.005) และ Praewa (−0.018) ใกล้กลุ่มอื่นมากกว่ากลุ่มตัวเองเล็กน้อย
- ถ้าเปิด `AUTO_K` จะได้ k = 2: 0.120, **k = 3: 0.129** (สูงสุด), k = 4: 0.110, k = 5: 0.109, k = 6: 0.090

(มี First 2 คน ระบบจึงต่อท้ายด้วยเลข 4 ตัวท้ายของรหัสนักศึกษาให้อัตโนมัติ)

ถ้าเพิ่มหรือเปลี่ยนรูปใน `dataset/` ผลจะเปลี่ยน ให้รัน `cluster.py` ใหม่แล้วอัปเดตตารางนี้

## ข้อจำกัด

- หน้าในห้องไม่ได้แยกเป็นกลุ่มชัดเจนตามธรรมชาติ ผลที่ได้ขึ้นกับจำนวนกลุ่ม `k` และ seed
- silhouette ทุกค่าต่ำ (ไม่ถึง 0.2) ยืนยันว่าหน้าในห้องไม่ได้แยกเป็นกลุ่มชัดเจน จำนวนกลุ่มที่ silhouette ดีที่สุดคือ 3 ไม่ใช่ 4
- หน้าเฉลี่ยของกลุ่มช่วยให้เห็นลักษณะร่วม แต่ยังไม่ได้บอกเป็นคำพูดว่าแต่ละกลุ่มแบ่งด้วยเกณฑ์อะไร

  และ `6752300411_tine.jpg` เป็นรูปผ่านฟิลเตอร์ลายเส้น ควรเปลี่ยนเป็นรูปปกติ
